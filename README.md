# Hata of Creations

Статический сайт студии Hata of Creations.

## Файлы
- `index.html` — структура сайта и содержимое страниц.
- `styles.css` — стили и оформление сайта.

## Локальный просмотр
Откройте `index.html` в браузере. Для публикации на Netlify выберите эту папку или подключите GitHub-репозиторий, где `index.html` и `styles.css` лежат в корне. Для обычного HTML/CSS сайта команда сборки не нужна, а папка публикации — корень (`.`).
